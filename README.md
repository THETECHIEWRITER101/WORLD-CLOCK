# WORLD-CLOCK (AuraClock)

AuraClock is a modern, feature-rich JavaFX-based desktop clock application.

## Features

* **Analog Clock View**: Beautifully designed analog clock interface.
* **Dashboard**: Comprehensive dashboard for time management.
* **Alarms**: Set, manage, and trigger customizable alarms.
* **Modern UI**: Styled with custom CSS for an elegant look and feel.

## Requirements

* Java 17 or higher
* Maven 3.6 or higher

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/THETECHIEWRITER101/WORLD-CLOCK.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WORLD-CLOCcK
   ```
3. Build and run the application using Maven:
   ```bash
   mvn clean javafx:run
   ```
